# 向日葵（Himawari）——简体中文版

这是Himawari 1.3.0的完整简体中文版本。剧情、分支、谜题、物品、时间循环、五种结局，以及阴谋板、日记、每日提示等功能均与英文版一致。原版手绘城市、所有原版画面和音乐保留不变。

## 开始游戏

解压游戏包，打开 `index.html`。或直接下载单文件 `Himawari-zh-CN.html`，保存后用浏览器打开。开始或继续游戏时，会启用音频。画面、中文旁白和配乐全部随包提供，离线可玩；无需账号、网络或API密钥。

点击或触摸选项和城市建筑。数字键1—4选择对应选项，回车继续，空格暂停或继续旁白，Esc关闭面板。设置中可以分别调整音乐、人声、朗读速度，也可以放大文字或减少动画。

游戏会自动保存。菜单→导出存档可备份或转移进度。浏览器对本地文件的存储行为各不相同，因此跨设备或跨文件游玩时，请使用导出和导入存档。

中文版使用独立的自动存档位置，不会覆盖英文版的自动存档。可以导入英文版导出的存档：原版进度、背包、日记、阴谋板和结局记录保留，系统文字改为中文。玩家自己写的猜想、连线标签和自取名字不会被擅自改写。

## 中文翻译与配音

翻译保留主角认真的偏执、孤独、突兀的自我辩护，以及原作的黑色幽默。没有增加剧情、重写人物或改变结局。固定姓名、地点、花名和教团用语保持一致。“猫腻”对话保留了可疑之事与猫之间的双关；密码“位数”和二十根手指脚趾的笑话也保留下来。

故事和选项共458条中文录音，使用ElevenLabs的Julian：年轻男性普通话音色，情绪方向参考英文版最初获准的Harry——紧张、郑重、担忧，流露真实的孤独感。英文版原有Harry录音没有更换。中文开场和两种备选音色的试听另行提供。音色根据语言、年龄与表现力资料选定；真人听感与方言、姓名发音仍欢迎玩家复核。

旁白全部预先录好，游戏不会调用任何语音服务。循环次数使用中文数词。姓名可使用中文；“马丁”与原版答案“Martin”等价。全角数字可以输入密码，错误答案仍会按原版规则处理。自由输入姓名使用同一位旁白的缓存字音或拼读片段；多音字使用默认字音及常见姓氏读音，特殊姓名的读法不一定唯一。

菜单、日记、柔和提示、已知死亡预报、背包、阅读历史、阴谋板、地图标记、过往选择、结局册和辅助朗读标签均已翻译。原版手绘继续按钮、学校和披萨店招牌以独立文字层覆盖原外文，原作者的PNG文件保留不变。1.4.0对网页使用的WebP进行轻量压缩，保持尺寸与透明度。中文字体来自设备本地的楷体、宋体等后备字体，仍保持原来的纸与墨界面。

## 编辑与构建

- `content/zh-CN.json`：中文故事译文，按原文编号保存。
- `content/literals.json`：`raw`是原版比较字符串；`text`是中文显示文本。不要修改 `raw`。
- `content/literals.en.json`：英文版对照，用于审校和存档兼容验证。
- `src/recovered-core.js`：恢复的原版控制逻辑，未修改。
- `src/locale.js`：中文显示、答题等价映射和跨语言存档适配。
- `src/audio.js`：离线音频播放器，保留1.3.0的加载与跳转修复。
- `content/narration.json`：每段中文录音的播放边界。
- `assets/narration-zh/`：中文音频及原始字级时间数据。
- `content/name-pronunciations.json`：姓名字音数据，源自MIT许可的pypinyin 0.55.0；许可附在 `content/pypinyin-LICENSE.txt`。
- `tests/`：原版对照、完整通关、存档、界面、音频与中文兼容测试。

运行 `python3 tools/build.py` 重建运行文件；加上 `--portable` 生成单文件版。运行 `python3 tools/package.py` 生成源码和itch.io游戏包。运行测试需要Node 24+、Python 3、FFmpeg/ffprobe、Pillow；`npm ci` 安装测试用DOM依赖。

`npm test` 验证18,000次动作与原版WASM一致、五个结局、261步合法通关以及逐步保存读取，还检查中文答题、英文存档迁移、日记与阴谋板、键盘与触摸事件、朗读跳转和所有资源。原版控制器、图画和配乐另与英文源码包逐字节比较。

中文录音另检查每条文字的时间数据，拒绝语音服务返回的未朗读后缀。所有完整录音均重复使用，仅对缺失部分补录短请求。缓存已随包提供，游玩和构建不需要重新生成。

这些检查包括DOM与模拟音频事件、文件完整性及字级时间数据，不等同于真人试听或真实设备的视觉检查。此前云浏览器阻止了本地预览，因此没有声称完成实时视觉检查。

开发用生成工具只能从项目外的私有密钥文件读取凭证。请不要把密钥复制到源码或游戏内。完整的英文版说明保存在 `README-English-release.md` 中，作为恢复过程的记录。

原版：https://liammchara.itch.io/himawari

## 1.4.0：先加载完整游戏

网页会在显示标题画面前，先下载25幅原画、全部中文旁白、13个音乐与音效文件，以及游戏运行文件。纸张风格的加载页显示实际已下载字节和百分比，同时最多下载三个文件。网络中断或长时间没有响应时可重试，已完整下载的文件保留。每个文件都核对大小与SHA-256；进入游戏后使用本地Blob地址，因此切换场景和跳转旁白无需再传输媒体文件。

浏览器允许时，完整下载会写入Cache API缓存。缓存地址包含各文件的内容哈希，下次访问可复用有效录音，更新游戏时仅重新下载有变化的文件。浏览器禁止缓存或空间不足时仍可完成本次下载并游玩，只是以后可能需要重新下载。浏览器清理缓存也可能导致重新下载。原有自动存档与下载缓存相互独立，不会因资源压缩或重试而改变。解压后的本地文件夹直接使用磁盘文件，单文件版已包含全部资源，因此无需网络加载。

原画从7,423,858字节压缩到2,523,312字节，减少66.0%。尺寸与透明通道均保持一致。较大的图画采用质量95的WebP，手写继续按钮及小型界面纹理仍为无损。源码中的原作者PNG及其哈希完全不变。资源测试核对透明度、哈希及至少40 dB的渲染PSNR。故事文本、原版规则、已缓存的旁白录音和所有配乐均未更改。

`src/preload.js`为下载与缓存逻辑，`content/preload-assets.json`记录完整下载清单，`tests/preload.mjs`测试首次加载、真实进度、返回缓存复用、重试、中断恢复、损坏文件、更新、缓存权限与容量、无响应下载、标题延迟显示，以及本地文件夹兼容性。`tools/optimize-art.py`可从原作者PNG重新生成轻量图画。

现已在公开的Cloudflare网站完成桌面浏览器实际验证：完整加载页、原版城市、本地Blob媒体地址、旁白进度、再次访问与存档恢复均通过。此验证不等同于手机视觉测试或真人试听。
